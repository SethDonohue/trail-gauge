The full-featured 0.3.0 build: setup wizard, swipeable gauge pages, alerts and mute buttons, hold-to-zero, quick settings, guides & tips, cabin and fog features.

It is restored as the latest release while its features are rebuilt into this repository. Builds 2–8 come from older code and are marked pre-release.

**Install:** open this release on the phone, download `trailgauge.apk` and open it. If one of builds 2–8 is installed, uninstall TrailGauge first: Android will not install a lower version (0.3.0 is version 3) over a higher one.
