# App icon

- `icon.png`: iOS and legacy Android launcher icon (1024 px, full bleed, no transparency).
- `adaptive-foreground.png` / `adaptive-monochrome.png`: Android adaptive icon layers; the
  background is the app's `#0b0d0e`. Monochrome is used for Android 13+ themed icons.
- `src/*.svg`: the sources. Re-render each at 1024 x 1024 if you change them.

Design: a 250-degree gauge arc (filled in the app's accent green) around a mountain on a
tilted horizon: the inclinometer, the trail and the gauge in one mark.
